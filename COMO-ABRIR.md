# Como abrir a Calculadora Albion no seu computador (Windows)

## Só na primeira vez

1. Instale o **Node.js** (versão LTS): https://nodejs.org/pt-br/download
   Baixe o instalador do Windows e vá clicando em "Próximo" até terminar.
2. Extraia o ZIP do projeto numa pasta, por exemplo `Documentos\Albion`.

## Para usar

Dê dois cliques em **Abrir Calculadora Albion.bat**.

- Na primeira vez ele instala algumas peças e monta a tela. Leva alguns minutos.
- Depois, o navegador abre sozinho em http://localhost:3001.
- Uma janela preta fica aberta enquanto o app roda. Para fechar o app, feche essa janela.

O app só funciona no seu computador: ninguém de fora consegue acessar.

## Se o Windows mostrar um aviso

Como o arquivo veio da internet, o Windows pode mostrar "O Windows protegeu o computador".
Clique em **Mais informações** e depois em **Executar assim mesmo**.
